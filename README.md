### 🚀 Things I've Built

- [agent-harness-demo](https://github.com/AdityaThakare72/agent-harness-demo): a minimal agent harness in Python, built in five stages (model alone, agent loop, tools, permissions and sandbox, context trimming), with a Gemini adapter and a fake model for tests
- [Legal-Agent-v2](https://github.com/AdityaThakare72/Legal-Agent-v2): RAG chatbot for Indian law that answers with citations from a knowledge base of legal acts
- [Research-Agent](https://github.com/AdityaThakare72/Research-Agent): multi-agent LangGraph system that researches a topic, drafts a blog post, critiques it and improves it
- [Report-Generation-Agent](https://github.com/AdityaThakare72/Report-Generation-Agent): multi-agent system (LangGraph + Gemini) that generates and validates suspicious activity reports for financial compliance
- [Industrial_Equipment_Maintenance](https://github.com/AdityaThakare72/Industrial_Equipment_Maintenance): end-to-end MLOps pipeline for predictive maintenance

### 🎓 Teaching

Alongside my data science work, I run sessions on Python, data science, ML, deep learning, GenAI and agentic AI for college batches, interns and faculty (FDPs). Most of the other repos on this profile are the code and material from those sessions.

- [deep-learning-complete](https://github.com/AdityaThakare72/deep-learning-complete): deep learning curriculum in both PyTorch and TensorFlow, from the perceptron to fine-tuning GPT-2
- [MET-Nashik-AUG-2026-GENAI](https://github.com/AdityaThakare72/MET-Nashik-AUG-2026-GENAI): 9-day workshop, deep learning to generative and agentic AI
- [Agentic_AI_FDP_PCCOER_SEP2026](https://github.com/AdityaThakare72/Agentic_AI_FDP_PCCOER_SEP2026): agentic AI FDP covering tools, workflows, human-in-the-loop, multi-agent and a capstone
- [DKTE-GEN-AI-AGENTIC-AI-SEP-2026](https://github.com/AdityaThakare72/DKTE-GEN-AI-AGENTIC-AI-SEP-2026): 2-day hands-on GenAI and agentic AI workshop for MCA students
